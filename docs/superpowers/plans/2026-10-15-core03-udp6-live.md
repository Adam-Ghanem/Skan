# CORE-03 live UDPv6 validation

Goal: close the explicitly documented non-loopback UDPv6 lab gap without weaker
correlation, fallback transports or fabricated MAC addresses.

Design: reuse the TCP adapter's interface-bound, exact-address kernel neighbor
cache lookup for UDP. Keep explicit MAC override and loopback behavior. Only an
already-resolved directly reachable IPv6 neighbor is supported; no new NDP
probing or off-link route guessing. Bound the existing netlink dump by a receive
timeout, monotonic total budget and batch limit, using owned descriptor cleanup.
No dependencies, network services or public targets are introduced.

Files: `include/net/network_scan_transport.hpp`,
`src/net/network_scan_transport.cpp`, `src/net/udp_network_scan_transport.cpp`,
`tests/integration/core_lab/core_lab.py`, and validation documentation.
